# roblox2web

Конвертер, который берёт **архив с исходником Roblox-проекта** (Rojo-структура или `.rbxlx`) и собирает из него **статическую веб-демо** (папка + zip), открываемую в браузере без сервера.

> ⚠️ **Честно о том, что это такое.** Это **не транслятор Luau → JavaScript** и не «волшебная кнопка» для любой Roblox-игры. Luau-код произвольных игр конвертировать нельзя.
> Инструмент делает другое: **читает данные** вашего проекта (таблицы `PetData`, `ZoneData`, `UpgradeData`, `Config` и т. п.), определяет жанр и **подставляет эти данные в готовый веб-шаблон** «pet / clicker simulator». Если проект устроен иначе — вы получите понятную ошибку или страницу-отчёт со списком найденных скриптов, а не «игру».

Пример результата: <https://joliks.github.io/pet-collector-sim/> (сгенерировано этим инструментом из проекта Pet Collector Simulator).
Онлайн-версия конвертора (всё работает в браузере, файлы никуда не загружаются): <https://joliks.github.io/roblox2web/>

## Что именно делает

1. Распаковывает `.zip` / `.tar.gz` / `.tgz` (защита от path traversal, лимиты размера и числа файлов, мусор `__MACOSX`/`.DS_Store` отбрасывается).
2. Загружает проект:
   * **Rojo**: `default.project.json` + дерево `.lua`/`.luau` (поддерживаются `init.lua`, `*.server.lua`, `*.client.lua`, `$path`, `$className`);
   * **`.rbxlx`** (XML-формат Roblox Studio): скрипты берутся из `Source`;
   * «голые» `.lua`-файлы без project.json (как ModuleScript'ы).
   * Бинарный `.rbxl` **не поддерживается** — получите понятное сообщение (сохраните как `.rbxlx` или экспортируйте Rojo-исходники).
3. Разбирает Luau собственным парсером (токенайзер + полный разбор синтаксиса, аннотации типов пропускаются) и **выполняет модули-данные в песочнице** (лимит 3 млн шагов, глубина вызовов ограничена). Поддерживаются: строки (в т. ч. длинные `[[ ]]` и interp-строки), числа, булевы, вложенные таблицы, комментарии, `local`-константы, простые функции-конструкторы (`local function pet(...) return {...} end`), цикл `for`, `table.insert`, `math.*`, `require` между модулями, `Color3`/`Vector3`/`Enum` как данные. Любые Roblox-сервисы (`game:GetService`, `Instance.new`, DataStore и т. д.) **не исполняются**: инструкция пропускается и попадает в предупреждения.
4. Классифицирует модули **по структуре**, а не только по имени (`petdata` — таблицы питомцев и яиц; `zonedata`; `upgradedata`; `config`; `formulas`).
5. Определяет жанр: `pet-simulator` (есть питомцы + яйца) → собирается играбельная веб-демо; всё остальное (в т. ч. тайкун) → **страница-отчёт** с списком скриптов и найденных данных. Тайкун распознаётся и называется, но игры для него нет.
6. Валидирует данные, подставляет умолчания шаблона там, где чего-то нет (**с предупреждением**), сверяет `Formulas.*` из вашего Luau с формулами шаблона на тестовых значениях и сообщает расхождения.
7. Пишет `index.html`, `style.css`, `game.js`, `i18n.js`, `data.js` (ваши данные), `conversion-report.json`, `CONVERSION_REPORT.txt` и zip.

## Что в игре-шаблоне

Клик/автосбор монет, яйца (5 редкостей, шансы из данных, удача, золотые питомцы), питомцы бегают за игроком и множат доход, апгрейды, миры/зоны, ребёрт, ежедневная награда, магазин геймпассов/продуктов (**только демо, без платежей**), фейковый лидерборд (**демо**), сохранение в `localStorage`, интерфейс RU/EN, адаптивная вёрстка. Подпись на странице: это браузерная демо-симуляция, а не сама Roblox-игра.

## Использование

Нужен только Python 3.9+ (без внешних зависимостей).

```bash
python roblox2web.py input.zip -o out/            # out/ + out.zip
python roblox2web.py input.tar.gz -o out/ --no-zip
python roblox2web.py input.zip -o out/ --zip build/site.zip
python roblox2web.py input.zip -o out/ --strict   # если игра не распознана — ошибка, ничего не создаётся
python roblox2web.py input.zip -o out/ --link "Исходники=https://github.com/me/game"   # ссылка в подвале
python roblox2web.py --serve                      # локальный загрузчик на http://127.0.0.1:8765
```

Коды выхода: **0** — собрана играбельная веб-демо; **3** — жанр не распознан, создана только страница-отчёт; **2** — ошибка (пустой/битый/неподдерживаемый архив, нет скриптов и т. п.), сообщение в stderr.

### Локальный загрузчик

`python roblox2web.py --serve` → откройте <http://127.0.0.1:8765>, перетащите архив, получите отчёт и кнопку «Скачать zip». Сервер слушает только `127.0.0.1`, лимит загрузки 120 МБ.

### Онлайн-версия (GitHub Pages)

Папка `docs/` — статический сайт: JS-порт парсера Luau (`js/luau.js`, `js/convert.js`) + вендорённый JSZip 3.10.1 (MIT). Архив обрабатывается целиком в браузере; есть предпросмотр результата и скачивание zip, кнопка «пример». `.tar.gz` читается через `DecompressionStream` (нужен современный браузер). Тесты проверяют, что **JS- и Python-версии выдают идентичные данные**.

## Структура репозитория

```
roblox2web.py      CLI
r2w/               luau.py (парсер+песочница), project.py (архивы, Rojo, rbxlx), extract.py (классификация, данные, сверка формул),
                   build.py (сборка результата), server.py (локальный загрузчик)
template/          веб-шаблон игры (index.html, style.css, game.js, i18n.js, report.html)
js/                luau.js, convert.js — порт конвертора для браузера/Node
web/               страница онлайн-конвертора; tools/build_docs.py собирает из неё docs/
docs/              собранная онлайн-версия (GitHub Pages: ветка main, /docs)
examples/          PetCollectorSimulator.zip — пример входного архива (без бинарников)
tests/             автотесты
dist/              roblox2web-1.0.0.zip — готовый дистрибутив
```

## Тесты

```bash
python -m unittest tests.test_luau tests.test_convert tests.test_js_parity tests.test_cli_server   # быстрые, без браузера
python -m unittest tests.test_browser     # нужен playwright (pip install playwright) и Chrome/Chromium
```

Покрыто: парсер Luau; конвертация Pet Collector Simulator (35 питомцев / 6 яиц / 5 зон / 5 апгрейдов, формулы совпали); **негативные случаи** — пустой файл, битый и обрезанный zip, мусор, архив без скриптов, `.rbxl`, битый `project.json`/`.rbxlx`, path traversal, проект без данных (→ отчёт), тайкун (→ отчёт), `--strict`, синтаксическая ошибка в Luau; паритет Python↔JS; CLI (коды выхода); локальный сервер; **Chromium через Playwright**: результат реально играбелен (клики, лимит кликов, яйцо → питомцы → апгрейд, зоны, ребёрт, ежедневная награда, сохранение, переключение языка, мобильный вид 390 px, битое сохранение) и онлайн-конвертор (пример, zip, tar.gz, не-игра → отчёт, неверные файлы).

Пересборка: `python tools/make_example.py` (пример-архив), `python tools/build_docs.py` (docs/).

## Ограничения

* Работает только для жанра pet / clicker simulator; логика механик — в шаблоне, а не в вашем коде. Экономические формулы (стоимость ребёрта, удача, размер сумки и др.) зашиты в шаблон; сверяется только модуль `Formulas`, если он есть.
* Данные в нестандартной форме (генерируются через `DataStoreService`, `Instance`-атрибуты, сложные метатаблицы, рантайм-код) могут не прочитаться — это попадёт в предупреждения или в отчёт.
* Графика упрощена (2D-канвас); модели, текстуры, звуки и GUI не переносятся.
* Сервер, DataStore, лидерборд, покупки — демо.
* Проверялось в Chromium; другие браузеры вручную не тестировались.
* Не используйте на чужих архивах без необходимости: хоть Luau и исполняется в песочнице без доступа к файлам/сети, это самописный интерпретатор, а не аудированный.
